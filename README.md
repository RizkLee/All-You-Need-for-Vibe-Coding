## 🗺️ 技术关系速查图

```
用户 (浏览器 / App / 小程序)
    │
    │  HTTP / WebSocket / gRPC
    ▼
【前端层】
  HTML + CSS + JavaScript
  框架: React / Vue / Angular
  样式: Tailwind CSS / Bootstrap
  构建: Vite / Webpack
  全栈框架: Next.js / Nuxt.js
  跨端: Flutter / React Native / Electron
    │
    │  API 调用 (REST / GraphQL)
    ▼
【后端层】
  运行时: Node.js / Python / Java / Go
  框架: Express / FastAPI / Spring / Gin
  认证: JWT / OAuth2
  中间件处理
    │
    │  查询 / 写入
    ▼
【数据层】
  关系型: PostgreSQL / MySQL
  文档型: MongoDB
  缓存: Redis
  ORM: Prisma / TypeORM / SQLAlchemy
    │
    ▼
【部署层】
  容器: Docker
  云平台: AWS / GCP / 阿里云 / Vercel
  CI/CD: GitHub Actions
  域名 + HTTPS
```

## 💡 如何使用本书

1. **新手入门**：从第一章顺序阅读，建立整体认知
2. **专项学习**：根据目录直接跳到感兴趣的章节
3. **技术选型**：参考第八章和第九章的实战案例
4. **Flutter开发者**：重点阅读 6.2、6.3，再结合第三章和第四章

> 💬 **Vibe Coding核心理念**：你不需要记住所有语法，但你需要知道地图。AI是你的代码生成器，你是架构师和决策者。
