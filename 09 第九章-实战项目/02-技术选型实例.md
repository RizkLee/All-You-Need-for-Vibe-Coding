# 9.2 技术选型实例

> 基于 TaskFlow 项目的实际需求，做出具体的技术选型决策，并说明理由。

---

## 选型决策过程

### 第一步：确定产品形态

TaskFlow 的需求：
- V1：Web 应用（最快上线）
- V2：移动端 App（iOS + Android）
- 需要用户登录和个人数据
- 有实时通知需求（V2）

结论：**以 Web 为主，架构上预留 App 扩展空间**。

---

### 第二步：前端选型

**候选方案**：
1. React SPA（前后端分离）
2. Next.js（全栈）
3. Vue + Nuxt.js

**选择：Next.js**

**理由**：
- 只有两个人开发，全栈框架减少项目配置成本
- 需要 SEO（希望搜索引擎能找到登录页和营销页）
- TypeScript 端到端类型安全，减少 bug
- Vercel 一键部署，运维成本低
- V2 的 App 后端可以复用 Next.js API Routes

---

### 第三步：数据库选型

**候选方案**：
1. PostgreSQL（关系型）
2. MongoDB（文档型）
3. Supabase（托管 PostgreSQL）

**选择：Supabase（基于 PostgreSQL）**

**理由**：
- 任务、项目、用户之间有明确的关联关系，关系型数据库合适
- Supabase 提供：数据库 + 认证 + Storage，不需要自建后端服务
- 有 V2 实时功能需求，Supabase Realtime 可以实现
- 有免费套餐，MVP 阶段零成本
- 未来如果流量大，可以迁移到自建 PostgreSQL

**没有选 MongoDB 的原因**：任务数据结构明确，有大量关联查询（任务→项目→用户），MongoDB 的 JOIN 能力弱。

---

### 第四步：认证选型

**候选方案**：
1. 自建（JWT + bcrypt）
2. NextAuth.js
3. Clerk
4. Supabase Auth

**选择：Supabase Auth（结合 NextAuth.js）**

**理由**：
- 已经选了 Supabase，Supabase Auth 与 Supabase 数据库的行级安全策略（RLS）深度集成
- 支持邮箱+密码 和 Google OAuth，满足 V1 需求
- 自建认证实现成本高，且容易出安全漏洞

---

### 第五步：部署选型

| 部分 | 选型 | 理由 |
|------|------|------|
| 前端/Next.js | Vercel | 与 Next.js 深度集成，零配置 CI/CD |
| 数据库 | Supabase（托管）| 无需自己运维 PostgreSQL |
| 文件存储 | Supabase Storage | 用户上传的任务附件 |
| 邮件 | Resend | 简单，开发者友好，有免费套餐 |
| 域名 | Cloudflare | 免费 CDN + DNS 管理 |

---

## 最终技术栈汇总

```
TaskFlow 技术栈

前端：
  框架：    Next.js 14（App Router）
  语言：    TypeScript
  样式：    Tailwind CSS + shadcn/ui
  状态：    Zustand（客户端状态）
  数据获取：React Query + Supabase Client

后端（Next.js API Routes + Supabase）：
  ORM：     Supabase（内置 PostgREST）+ Prisma（复杂查询）
  认证：    Supabase Auth
  邮件：    Resend

数据层：
  主数据库：Supabase PostgreSQL
  文件存储：Supabase Storage
  缓存：    暂无（V1 不需要）

部署：
  应用：    Vercel
  数据库：  Supabase
  域名：    Cloudflare
  邮件：    Resend

V2 规划（App）：
  App：     Flutter
  实时：    Supabase Realtime
  推送：    Firebase Cloud Messaging
```

## 这套技术栈的成本估算

**V1 上线阶段（< 1000 用户）**：

| 服务 | 月费用 |
|------|--------|
| Vercel（免费套餐）| $0 |
| Supabase（免费套餐）| $0 |
| Resend（免费套餐）| $0 |
| Cloudflare（免费）| $0 |
| 域名 | $12/年 |
| **总计** | **约 $1/月** |

随着用户增长，再按需升级到付费套餐。这是 Vibe Coding 时代典型的"零成本起步"方案。
