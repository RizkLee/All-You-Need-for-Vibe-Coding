# 2.11 前端状态管理

> 当应用的数据需要在多个组件间共享时，状态管理成为必须解决的问题。

---

## 问题的根源

React 和 Vue 的基本数据流是**从父到子**：父组件把数据通过 props 传给子组件。

但当应用变复杂，这个模式会遇到问题：

```
App（持有"是否登录"状态）
├── Header（需要显示用户名）
│   └── UserAvatar（需要用户头像）
├── Sidebar（需要根据登录状态显示不同菜单）
└── MainContent
    └── UserProfile（需要用户数据）
        └── UserPosts（也需要用户数据）
```

如果把 `user` 数据从 `App` 逐层传下去：
`App → Header → UserAvatar`（传了 2 层）
`App → MainContent → UserProfile → UserPosts`（传了 3 层）

这叫 **Props Drilling（属性穿透）**——数据要穿过很多中间组件，那些中间组件根本不需要这个数据，只是负责"转发"。代码很难维护。

---

## 状态的分类

| 类型 | 描述 | 例子 |
|------|------|------|
| **本地状态** | 只属于某个组件 | 弹窗是否打开、输入框内容 |
| **共享状态** | 多个组件都需要 | 当前登录用户、购物车数据 |
| **服务端状态** | 来自后端的数据 | 用户列表、产品列表 |
| **URL 状态** | 当前页面路由、查询参数 | 搜索关键词在 URL 中 |

不同类型的状态用不同的工具管理。

---

## 方案一：React Context（内置）

React 内置的跨组件状态共享方案：

```jsx
// 1. 创建 Context
const UserContext = createContext(null)

// 2. 在顶层提供数据
function App() {
  const [user, setUser] = useState(null)
  
  return (
    <UserContext.Provider value={{ user, setUser }}>
      <Header />
      <MainContent />
    </UserContext.Provider>
  )
}

// 3. 在任意子组件消费
function UserAvatar() {
  const { user } = useContext(UserContext)
  return <img src={user?.avatar} />
}
```

**适合**：简单的全局状态（主题、当前用户、语言设置）
**不适合**：频繁更新的数据（每次更新会重渲染所有消费者）

---

## 方案二：Zustand（轻量状态管理库）

**Zustand** 是目前 React 生态中最受欢迎的轻量状态管理库：

```javascript
// store.js — 定义状态
import { create } from 'zustand'

const useCartStore = create((set) => ({
  items: [],
  totalCount: 0,
  
  addItem: (product) => set((state) => ({
    items: [...state.items, product],
    totalCount: state.totalCount + 1
  })),
  
  removeItem: (id) => set((state) => ({
    items: state.items.filter(item => item.id !== id),
    totalCount: state.totalCount - 1
  })),
  
  clearCart: () => set({ items: [], totalCount: 0 })
}))
```

```jsx
// 在任何组件中使用，不需要 Provider 包裹
function CartIcon() {
  const totalCount = useCartStore(state => state.totalCount)
  return <div>购物车 ({totalCount})</div>
}

function ProductCard({ product }) {
  const addItem = useCartStore(state => state.addItem)
  return (
    <button onClick={() => addItem(product)}>加入购物车</button>
  )
}
```

## 方案三：Redux（功能完备，较重）

**Redux** 是历史上最流行的状态管理库（React 官方推荐），但因为模板代码多，现在很多项目转向 Zustand。

现代 Redux 用 **Redux Toolkit（RTK）** 简化配置：

```javascript
import { createSlice, configureStore } from '@reduxjs/toolkit'

// 定义 slice（状态切片）
const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: state => { state.value += 1 },
    decrement: state => { state.value -= 1 },
  }
})

// 创建 store
const store = configureStore({
  reducer: { counter: counterSlice.reducer }
})

// 在组件中使用
function Counter() {
  const count = useSelector(state => state.counter.value)
  const dispatch = useDispatch()
  return (
    <div>
      {count}
      <button onClick={() => dispatch(counterSlice.actions.increment())}>+</button>
    </div>
  )
}
```

**适合大型项目**，特别是需要可预测性、时间旅行调试、复杂异步逻辑的场景。

## 方案四：服务端状态管理（React Query / SWR）

来自后端的数据有其特殊性：需要请求、有加载状态、可能失败、需要缓存、需要定时刷新。

**React Query**（现在叫 TanStack Query）专门处理这类"服务端状态"：

```jsx
import { useQuery, useMutation } from '@tanstack/react-query'

function UserList() {
  // 自动处理加载、错误、缓存
  const { data: users, isLoading, error } = useQuery({
    queryKey: ['users'],
    queryFn: () => fetch('/api/users').then(res => res.json()),
    staleTime: 5 * 60 * 1000  // 5分钟内不重新请求
  })
  
  if (isLoading) return <Spinner />
  if (error) return <ErrorMessage />
  
  return (
    <ul>
      {users.map(user => <li key={user.id}>{user.name}</li>)}
    </ul>
  )
}
```

React Query 还自动处理：
- 数据缓存（同样的请求不重复发）
- 后台重新获取（切换标签页回来自动刷新）
- 乐观更新
- 分页和无限滚动

## Vue 的状态管理：Pinia

Vue 的官方状态管理库 **Pinia** 设计简洁：

```javascript
// stores/cart.js
import { defineStore } from 'pinia'

export const useCartStore = defineStore('cart', {
  state: () => ({
    items: [],
  }),
  getters: {
    totalCount: (state) => state.items.length,
    totalPrice: (state) => state.items.reduce((sum, item) => sum + item.price, 0)
  },
  actions: {
    addItem(product) {
      this.items.push(product)
    },
    removeItem(id) {
      this.items = this.items.filter(item => item.id !== id)
    }
  }
})
```

```vue
<!-- 在组件中使用 -->
<script setup>
import { useCartStore } from '@/stores/cart'
const cart = useCartStore()
</script>

<template>
  <div>共 {{ cart.totalCount }} 件，合计 ¥{{ cart.totalPrice }}</div>
  <button @click="cart.addItem(product)">加入购物车</button>
</template>
```

## 如何选择状态管理方案

```
数据只在一个组件内用？
  → 用组件内的 useState / ref

数据在少数几个相邻组件间共享？
  → 提升到父组件（状态提升）

数据是来自后端的服务器数据？
  → React Query / SWR

全局UI状态（主题、用户、购物车）？
  → React: Zustand 或 Context
  → Vue: Pinia

大型复杂应用，需要严格可追溯？
  → Redux Toolkit
```
