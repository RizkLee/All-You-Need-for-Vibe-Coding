# 2.12 前端路由管理

> 单页应用（SPA）中，路由决定了用户在哪个"页面"，但实际上整个应用只有一个 HTML 文件。

---

## 传统网站 vs 单页应用

**传统多页应用（MPA）**：
```
用户点击"关于我们"
  → 浏览器向服务器请求 /about.html
  → 服务器返回完整的 HTML 文件
  → 浏览器重新加载整个页面
```

**单页应用（SPA）**：
```
用户点击"关于我们"
  → JavaScript 拦截导航
  → 根据路径 /about 渲染对应组件
  → 只更新变化的部分，不重新加载页面
```

SPA 的优势：
- 页面切换流畅，没有白屏
- 只需要加载一次 JS/CSS 资源
- 更接近原生 App 的体验

## 前端路由的工作原理

前端路由有两种模式：

### Hash 模式
```
URL 示例：https://example.com/#/about

原理：# 后面的内容（hash）变化时，浏览器不会向服务器发请求，
     JS 监听 hashchange 事件来切换组件
     
优点：不需要服务器配置
缺点：URL 有 # 符号，不美观；不利于 SEO
```

### History 模式（推荐）
```
URL 示例：https://example.com/about

原理：利用 HTML5 History API（pushState），修改 URL 但不触发页面刷新，
     JS 监听 popstate 事件来切换组件
     
优点：URL 干净；对 SEO 友好
缺点：需要服务器配置（所有路径都返回 index.html）
```

## React Router

**React Router** 是 React 生态中最主流的路由库（v6 版本）：

### 基本用法

```jsx
import { BrowserRouter, Routes, Route, Link, useNavigate, useParams } from 'react-router-dom'

// 根组件：配置路由
function App() {
  return (
    <BrowserRouter>
      {/* 导航 */}
      <nav>
        <Link to="/">首页</Link>
        <Link to="/products">产品列表</Link>
      </nav>
      
      {/* 路由出口 */}
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/products" element={<ProductListPage />} />
        <Route path="/products/:id" element={<ProductDetailPage />} />
        <Route path="/dashboard/*" element={<Dashboard />} />
        <Route path="*" element={<NotFoundPage />} />
      </Routes>
    </BrowserRouter>
  )
}

// 带参数的页面
function ProductDetailPage() {
  const { id } = useParams()  // 获取 URL 中的 :id 参数
  return <div>产品 ID: {id}</div>
}

// 编程式导航
function LoginPage() {
  const navigate = useNavigate()
  
  const handleLogin = () => {
    // 登录成功后跳转
    navigate('/dashboard')
  }
  
  return <button onClick={handleLogin}>登录</button>
}
```

### 嵌套路由

```jsx
function Dashboard() {
  return (
    <div>
      <Sidebar />
      {/* 子路由的出口 */}
      <Outlet />
    </div>
  )
}

<Route path="/dashboard" element={<Dashboard />}>
  <Route index element={<DashboardHome />} />        {/* /dashboard */}
  <Route path="profile" element={<ProfilePage />} />  {/* /dashboard/profile */}
  <Route path="settings" element={<SettingsPage />} /> {/* /dashboard/settings */}
</Route>
```

### 路由守卫（权限保护）

```jsx
// 保护需要登录才能访问的路由
function ProtectedRoute({ children }) {
  const { user } = useAuth()
  
  if (!user) {
    return <Navigate to="/login" replace />  // 未登录，重定向到登录页
  }
  
  return children
}

// 使用
<Route path="/dashboard" element={
  <ProtectedRoute>
    <Dashboard />
  </ProtectedRoute>
} />
```

## Vue Router

Vue 的官方路由库，配置方式略有不同：

```javascript
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', component: HomePage },
    { path: '/products', component: ProductListPage },
    { path: '/products/:id', component: ProductDetailPage },
    {
      path: '/dashboard',
      component: DashboardLayout,
      meta: { requiresAuth: true },  // 自定义元信息
      children: [
        { path: '', component: DashboardHome },
        { path: 'profile', component: ProfilePage }
      ]
    }
  ]
})

// 全局路由守卫
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !isLoggedIn()) {
    return '/login'
  }
})

export default router
```

```vue
<!-- 在模板中使用 -->
<template>
  <nav>
    <RouterLink to="/">首页</RouterLink>
    <RouterLink to="/products">产品</RouterLink>
  </nav>
  
  <!-- 路由出口 -->
  <RouterView />
</template>

<script setup>
import { useRouter, useRoute } from 'vue-router'

const router = useRouter()
const route = useRoute()

// 获取参数
console.log(route.params.id)

// 编程式导航
router.push('/dashboard')
router.push({ name: 'product-detail', params: { id: 123 } })
</script>
```

## URL 参数的类型

```
路径参数（Path Params）：/products/:id
  → 用于标识特定资源
  → 如 /products/123

查询参数（Query Params）：/products?category=phone&sort=price
  → 用于过滤、排序、分页等可选参数
  → 不会改变资源的标识

// React 中读取查询参数
import { useSearchParams } from 'react-router-dom'
const [searchParams] = useSearchParams()
const category = searchParams.get('category')  // "phone"
```

## 路由与 SEO

SPA 最大的问题：搜索引擎爬虫看到的只是一个空的 HTML，JavaScript 还没有运行，看不到内容。

解决方案：
- **服务端渲染（SSR）**：在服务器上运行 React/Vue，直接返回渲染好的 HTML
- **静态站点生成（SSG）**：构建时预先生成所有页面的 HTML

Next.js（React）和 Nuxt.js（Vue）提供了 SSR/SSG 能力，详见第五章。
